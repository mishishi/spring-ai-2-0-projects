# 员工手册

## 1. 入职流程

- 提交入职材料(身份证 / 学历 / 前公司离职证明)
- 签署劳动合同(3 年期,试用期 3-6 个月)
- 参加新员工培训(1 周,HR + 部门)
- 配置办公设备(笔记本 / 工卡 / 邮箱)

## 2. 薪资福利

- 月薪:15 号发放(遇节假日提前)
- 年终奖:1-3 个月工资(根据公司业绩)
- 五险一金:按国家规定缴纳
- 补充医疗:公司额外购买的商业医疗保险

## 3. 晋升通道

- 每年 2 次晋升评审(4 月 / 10 月)
- 晋升标准:绩效 + 能力 + 司龄
- 晋升幅度:10%-30% 调薪
- 跨部门转岗:每年 1 次申请机会

## 4. 离职流程

- 提前 30 天提交书面申请
- 完成工作交接
- 归还公司资产(笔记本 / 工卡 / 钥匙)
- HR 办理离职手续 + 社保转移
- 最后 1 个工作日领取离职证明
