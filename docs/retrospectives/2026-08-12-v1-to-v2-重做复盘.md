### D-19: 2.0 builder API 简化
```java

// 2.0
PgVectorStore.builder().dimensions(1536).distanceType(...).indexType(...)
```

### D-25: 纯 Spring AI 2.0 官方,无 LangChain4j
- 用户明确选:**不用 LangChain4j bridge**
- Spring AI 2.0 已原生支持 @Tool / ToolCalling / MCP / Streamable HTTP / MessageWindowChatMemory
- LangChain4j 是另一套体系,混用增加复杂度

### D-27: 0 网络 + 真 LLM 双路径 Pattern
```java
@Service
public class MyService {
    private final ChatClient chatClient;

    public MyService(ChatClient.Builder builder /*, deps */) {
        this.chatClient = (builder == null) ? null : builder.defaultSystem("...").build();
    }

    public String run(String input) {
        if (chatClient == null) {
            return mockAnswer(input);  // 0 网络可测
        }
        return chatClient.prompt().user(input).call().content();  // 真实 LLM
    }
}
```
**好处**:单测 `new MyService(null)` 秒过,Spring 注入时 `ChatClient.Builder` 自动可用。

### D-28: Vercel 路径不带 `/index.html` 后缀
- 本地 `mkdocs serve`:`/01-hello-world/index.html`
- Vercel 部署:`/01-hello-world/` (被 rewrite 掉)
- 影响:`endsWith('/index.html')` 永远 false → `body.md-home` class 永远不加 → v1 杂志风 CSS 全部不生效
- 修复:JS pathname check 改用正则 `/\/[^/]+\/?$/`

## 4. 5 大踩坑(重点复盘)

### 坑 1: Spring AI 2.0 砍了 `spring-ai-vector-store-simple`

**症状**:`mvn test` 报 `'dependencies.dependency.version' for org.springframework.ai:spring-ai-vector-store-simple:jar is missing`

**原因**:1.1.x 时代有的 SimpleVectorStore starter,2.0 删了(只剩基础 jar + pgvector + milvus)。

**解法**:
- P2 doc-qa 项目**不**用 VectorStore 抽象,改用中文 2-gram 关键词检索 + 模板化答案
- 牺牲语义检索精度,换取 0 网络 + 0 依赖
- 真实生产换 `spring-ai-starter-vector-store-pgvector`(需 Docker)

**教训**:Spring AI 2.0 文档不完整,新项目开工前先 `find ~/.m2/repository/org/springframework/ai -name "*vector*"` 确认 artifact 名。

### 坑 2: Spring AI Graph 实际在 Alibaba 生态,不在 spring-ai 主线

**症状**:Maven 找不到 `org.springframework.ai:spring-ai-graph`(主线没发布)。

**实际状态**:
- ✅ `com.alibaba.cloud.ai:spring-ai-alibaba-graph` 在 Alibaba 仓库
- spring-ai 主线 PR 在 review,可能 2.x 后期合并

**解法**:chapter 17 自己写简化版 Graph 抽象(`Graph` / `GraphNode` / `addEdge` / `addConditionalEdge` / `run(maxSteps)`),满足状态机核心需求。

**教训**:"Spring AI 2.0 全套支持 Agent" 是营销话术,具体 API 可能散落在 Alibaba 生态或第三方实现,需要 verify。

### 坑 3: Java 17 不支持 patterns in switch

**症状**:`case int c when c <= 5 -> "simple"` 编译报"patterns in switch statements 是预览功能"。

**解法**:改传统 if-else:
```java
String level;
if (complexity <= 5) level = "simple";
else if (complexity <= 10) level = "moderate";
else if (complexity <= 20) level = "complex";
else level = "untestable";
```

**教训**:写 Java 17 代码时避免 patterns in switch,用 if-else chain 或 EnumMap。

### 坑 4: Vercel `endsWith('/index.html')` 永远 false

**症状**:v1 杂志风 `body.md-home::before` 装饰 header + drawer 唤起,在 Vercel 部署后**完全不显示**。

**debug 套路**(puppeteer):
```js
await page.goto('https://site/01-hello-world/');
const info = await page.evaluate(() => ({
    bodyClass: document.body.className,  // 应该是 'md-home' 但实际是 ''
    pathname: location.pathname,         // 关键! /01-hello-world/ 不是 /01-hello-world/index.html
}));
```

**根因**:Vercel static hosting 把 `/01-hello-world/index.html` rewrite 成 `/01-hello-world/`,跟本地 mkdocs serve 不同。

**修复**:
```js
const p = window.location.pathname;
if (p === '/' || p.endsWith('/index.html') || /\/[^/]+\/?$/.test(p)) {
    document.body.classList.add('md-home');
}
```

**教训**:**永远 Vercel 实地测试**,不要相信本地 mkdocs serve 的 JS 行为。

### 坑 5: 中文 2-gram + 单字噪音

**症状**:query "天气怎么样" 命中 doc "今天 7 天内提交"(因为 "天" 单字),top-K 退化成"返回任何 doc"。

**根因**:中文按字切 token,单字("天"/"是"/"了")命中几乎所有 doc。

**解法**:中文 2-gram + 过滤 length >= 2:
```java
// 中文每 2 字一个 token,过滤单字
return tokens.stream().filter(t -> t.length() >= 2).toArray(String[]::new);
```

**教训**:任何中文检索(关键词 / embedding 前的粗筛)都要 2-gram。

### 坑 6(bonus): String.indexOf 大小写不一致

**症状**:`text.toLowerCase()` + `indexOf("RAG")` 永远返回 -1。

**根因**:"RAG" 没 lowercase,跟 lower-case 的 doc 文本不匹配。

**修复**:
```java
String tLower = t.toLowerCase();
lower.indexOf(tLower);
```

**教训**:写任何 `indexOf` 检索,两边都 `toLowerCase(Locale.ROOT)`(注意 Locale 避免 Turkish i 陷阱)。

## 5. 意外发现

### 5.1 Vercel `vercel --prod` 自动 alias

- **v1 时期**:必须 `vercel alias set <url> <project>.vercel.app` 手动
- **v2 现在**:自动切 main alias,输出最后显示 `▲ Aliased   https://project.vercel.app`
- 仍然 `vercel alias ls` 永远确认

### 5.2 Spring Boot 4.0 + Java 17 + Spring AI 2.0 组合稳

- 43 个 commit 没遇到 Spring Boot 4.0 兼容性问题
- Spring AI 2.0 文档缺,但代码可读性 OK
- Java 17 records + 紧凑构造器很香

### 5.3 mkdocs-material 9.5 移除了 `body.md-home` class

- v1 老版用 `body.md-home::before` 装饰 header,**本地能跑,线上不生效**
- 9.5 templates 里 `is_homepage` 是 jinja 变量,但没渲染到 body class
- 解决:`extra.js` 动态加 class,根据 pathname

### 5.4 Spring AI 2.0 实际 API 完整性

- ✅ ChatClient:完整
- ✅ RAG(RetrievalAugmentationAdvisor):完整
- ✅ @Tool:完整
- ✅ MCP:Server/Client 都有
- ✅ ChatMemory(MessageWindowChatMemory):完整
- ❌ Graph:仅 Alibaba 生态
- ⚠️ SimpleVectorStore:无 starter,需自己处理

### 5.5 Maven multi-module 0 网络测试的最佳实践

- 每个 module 独立 pom.xml,继承 parent
- parent BOM 统一 Spring Boot 4.0.0 + Spring AI 2.0.0
- 子 module 依赖 `spring-boot-starter-test`(自带 JUnit 5 + Mockito + AssertJ)
- 写测试时**不**用 `@MockBean` 注入 ChatClient,而是直接 `new MyService(null)`
