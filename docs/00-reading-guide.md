# 第 0 章 · 导读

> 写给有 Java 基础、没用过 LLM 的工程师

## 这个系列能给你什么

学完 20 周后,你能:

- ✅ 用 Spring AI 2.0 搭建 LLM 应用(从 Hello World 到生产级)
- ✅ 独立完成 RAG(检索增强生成)系统
- ✅ 搭建 Multi-Agent 协作应用
- ✅ 跟 GitLab / Notion / Slack 等真实系统集成(MCP)
- ✅ 5 个完整可上线的项目作为作品集

## 读者画像

| 你应该是 | 不是 |
|---|---|
| ✅ Java 工程师,会用 Spring Boot | ❌ 没用过 Spring |
| ✅ 写过 REST API | ❌ 完全没后端经验 |
| ✅ 了解 LLM 是什么(用过 ChatGPT) | ❌ 完全没碰过 AI |
| ✅ 想做 LLM 应用(应用层) | ❌ 想搞 LLM 模型训练(算法层) |
| ✅ 有时间每周 10-15 小时 | ❌ 只想 3 天速成 |
