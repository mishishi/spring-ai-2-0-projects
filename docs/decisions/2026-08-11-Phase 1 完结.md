## 关键工程套路(可复用)

### 套路 1:每个 chapter 一个 Maven module
- 独立 pom.xml,继承根 BOM
- `git -C <root> -pl <chapter> -am test` 验证单个
- 整个仓库 `mvn test` 全验证

### 套路 2:CommandLineRunner 演示
- ch1-5 不用 web,所有 demo 在 CommandLineRunner 里
- 跑 `mvn spring-boot:run` 看日志
- 测试用 `@Profile("!test")` 屏蔽

### 套路 3:WebFlux + SSE(ch6 起)
- `controller.stream().content()` 返回 `Flux<String>`
- `produces = MediaType.TEXT_EVENT_STREAM_VALUE`
- 浏览器 `EventSource` 接收

### 套路 4:0 网络测试
- 永远不连真实 LLM
- `application.yml` 默认 `api-key: ${OPENAI_API_KEY:fake-key-for-tests}`
- `@Profile("!test")` + `@ActiveProfiles("test")` 双向屏蔽
- `@SpringBootTest(webEnvironment = NONE)`(ch1-5)或 MOCK(ch6)
