## 决策

### D-18:用 Docker pgvector(5433 端口,避开 macOS 本地 PG 5432)

**坑**:用户 macOS 本地有 PostgreSQL 服务(`postgres 1023 zhurenbao`)在 5432 端口,Docker 端口转发被覆盖,JDBC 客户端连到了本地 PG(密码不一致 → "role does not exist")。

**解法**:Docker 用 `-p 5433:5432`,application.yml 用 `localhost:5433`。

**验证**:
```bash
$ lsof -i :5432
postgres  1023  zhurenbao  ...  TCP localhost:postgresql (LISTEN)  ← macOS 本地
com.docke 54583 zhurenbao  ...  TCP *:postgresql (LISTEN)         ← Docker
$ PGPASSWORD=postgres psql -h 127.0.0.1 -p 5433 -U postgres -d vectordb -c "SELECT 1"
?column? | current_user
----------+--------------
       1 | postgres
✅
```

### D-19:Spring AI 2.0.0 PgVectorStoreBuilder API 命名简化

**1.x 风格**:`.withDimensions(1536).withDistanceType(...).withIndexType(...)`

**2.0.0 风格**:`.dimensions(1536).distanceType(...).indexType(...)`(去掉 `with` 前缀)

**2.0.0 builder 实际方法**:
- `schemaName(String)`
- `vectorTableName(String)`
- `idType(PgIdType)`
- `vectorTableValidationsEnabled(boolean)`
- `dimensions(int)` ← 不是 withDimensions
- `distanceType(PgDistanceType)` ← 不是 withDistanceType
- `indexType(PgIndexType)` ← 不是 withIndexType
- `initializeSchema(boolean)`
- `maxDocumentBatchSize(int)`
- `removeExistingVectorStoreTable(boolean)`
- `build()`
