## 关键工程决策

### D-7:`@SpringBootTest` 用 `WebEnvironment.NONE`

Chapter 1 没有 web 端点,只需要 `CommandLineRunner` 跑一次。`@SpringBootTest` 默认启动 mock servlet context,需要 `jakarta.websocket-api`,而 chapter 1 不该引入 web 依赖。

**解法**:
```java
@SpringBootTest(webEnvironment = SpringBootTest.WebEnvironment.NONE)
```

后续 chapter 加 `@RestController` 时,改回默认即可。

### D-8:CommandLineRunner 用 `@Profile("!test")` 屏蔽

避免测试时 CommandLineRunner 注入 `ChatClient` 后,真实调用 LLM(因为 api-key 是 fake 的,会 401)。

**Pattern**:
```java
@Bean
@Profile("!test")
CommandLineRunner helloWorld(ChatClient.Builder builder) { ... }
```

测试用 `@ActiveProfiles("test")` 屏蔽。

### D-9:子 module `relativePath` 显式指定

子 module 在 `01-basics/01-hello-world/`,父 pom 在根,默认相对路径 `../pom.xml` 不够,要 `../../pom.xml`。

```xml
<parent>
    ...
    <relativePath>../../pom.xml</relativePath>
</parent>
```
