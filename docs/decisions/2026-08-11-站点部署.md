### D-23:Vercel 部署踩坑(4 个)

**坑 1: Vercel Python 用 uv 管理,pip install 被拦截**
- 错误:`This environment is externally managed` / `error: externally-managed-environment`
- 解法:`python -m pip install --break-system-packages -r requirements.txt`

**坑 2: pymdownx 10.x 跟 Python 3.14 兼容 bug**
- 错误:`AttributeError: 'NoneType' object has no attribute 'replace'` in `html.escape`
- 根因:pygments 2.19+ 传 None 给 `html.escape`,Python 3.14 报 None
- 解法:锁 `pygments==2.18.0`

**坑 3: mkdocs-material 9.5 锁 pymdownx>=10.2**
- 跟坑 2 冲突(pymdownx 10.2 跟 Python 3.14 兼容 bug)
- 解法:同样锁 pygments 2.18.0(不锁 pymdownx,跟 mkdocs-material 9.5 兼容)

**坑 4: .python-version 改 Python 3.13 不生效**
- Vercel 默认锁 Python 3.14,`.python-version` 文件被忽略
- 解法:不绕 Python 版本,改用锁依赖
