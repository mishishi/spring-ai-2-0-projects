# 2026-08-11 Chapter 6 - Streaming

## 背景

Phase 1 最后一章,WebFlux + SSE 实现流式 LLM 输出。

## 决策

### D-14:Chapter 6 用 WebFlux(不是 WebMVC)

**为什么**:
- Spring AI 1.x 的 `stream().content()` 返回 `Flux<String>`,需要响应式支持
- WebFlux 是 Spring 官方推荐的流式方案
- SSE 协议在 WebFlux 上一行配置:`MediaType.TEXT_EVENT_STREAM_VALUE`
- WebMVC 也能跑(2.0 改进),但 WebFlux 性能更好

**取舍**:
- ✅ 流式 / 长连接 / 高并发 优
- ❌ 不能用 `@Controller` 的同步 ThreadLocal 模式(基本不用,影响小)

### D-15:用 PageController 返回单文件 HTML(不分离)

**为什么**:
- chapter 6 重点是后端 SSE,前端只是 demo
- 单文件 HTML 容易看,无前端构建
- `EventSource` 12 行代码搞定
- 真实项目可以拆 React / Vue(后续 project 1 会做)

**模式**:
```java
@GetMapping(value = "/", produces = MediaType.TEXT_HTML_VALUE)
@ResponseBody
public String index() {
    return """
        <!DOCTYPE html>
        ...
        <script>
          new EventSource('/api/chat/stream?q=...').onmessage = ...
        </script>
        """;
}
```
