## 这是什么

面向**有 Java 基础、会 Spring Boot、没用过 LLM** 的工程师,从零开始学 Spring AI 2.0。

跟其他教程的区别:
- ✅ **每个 chapter 配独立可跑的项目**
- ✅ **5 个完整可上线项目**(不是 demo 级)
- ✅ **0 网络 0 Docker**(测试纯本地,跟 LLM 交互用 mock)
- ✅ **20 周节奏**(适合跟学)

## 4 阶段路线

| 阶段 | 周 | 主题 | 实战项目 |
|---|---|---|---|
| 🌱 **Phase 1** | W1-4 | 基础筑基(Hello World → Streaming) | AI 周报生成器 |
| 🌿 **Phase 2** | W5-10 | RAG 实战(Embeddings → 高级检索) | 企业文档问答助手 |
| 🌳 **Phase 3** | W11-16 | Agent 实战(Tool → Multi-Agent → Graph) | AI 旅行规划助手 |
| 🚀 **综合** | W17-20 | 完整产品(RAG + Agent + MCP) | AI Code Review 助手 |

## 快速开始

```bash
git clone https://github.com/mishishi/spring-ai-2-0-projects.git
cd spring-ai-2-0-projects

# 进入 phase 1 第一个 chapter
cd 01-basics/01-hello-world
mvn spring-boot:run
```
